# H006-d incelemesi

15 Kasım 2026. Ana ajan, Ponytail full ve review kapsamında üretim launch akışını, Rust test çağıranlarını ve pinned Python controller'ın ilk `start` okumasını inceledi. Değişiklikler Windows test derlemesinde kalır. Başlatma ve kapatma sözleşmesi aynı üretim yollarından çalışır.

Observer yalnız kendi başlattığı test sahibini doğrudan Child handle ile sonlandırır. Controller process ve boru handle'ları bu sahipten kopyalanır. Test sahibi, gözlemcinin Job'ına katılmadan controller başlatamaz. Ölçüm sırasında bu Job açık kalır. Üretim Job üyeliği kontrol noktası öncesinde kurulmamıştır. Kümülatif süreç sayımı, helper hemen kapanmış olsa bile yeni süreç yakalar. Her iki kolda eksiksiz EOF ve beklenen exit 2, boş controller stdout ile birlikte kontrol edilir.

İlk uygulama dış Job'da yalnız iki süreç varsayıyordu. Windows'un oluşturduğu iki konsol barındırıcısı bu varsayımı geçersiz kıldı. Sınıflandırma mevcut test tanı yollarını yeniden kullanır. Başlangıçtan sonra yeni süreç oluşması veya son Job'ın boşalmaması hâlâ hata sayılır. Eski stage pin reddi de bağımsız başarısız kayıt olarak tutuldu. [Kanıt referansları](../proofs/windows-engine-startup-crash.json).

Nihai odaklı çalışma iki kontrolü geçti. Son Rust testi ve embedded build kaynak fingerprint'leri odaklı çalışma ile eşleşti. Değişmeyen frontend sonucu yeniden kullanıldı. Kabulü engelleyen yerel bulgu kalmadı. Başka kurulum, işletim sistemi, etkin trafik veya uzun süreli kararlılık kapsamı ayrı kalır.
