# H034 değişiklik incelemesi

8 Kasım 2026; ana ajan Ponytail kabul incelemesi. Değişiklik salt okunur bağlantı teşhisi ve güvenli sonraki adım sunar. Beklenen yük tek yerel kullanıcı, mevcut 5s runtime poll'u ve her açık eylemde tek teşhistir; sağlayıcı veya otomatik onarım çalıştırılmaz.

Bağlı akış okundu: `App → ProblemNotice → recovery client → get_recovery_snapshot → RecoveryManager → DiscoveryManager.recovery_scan / PlanManager.recovery_config / OverviewManager.read_activity / RuntimeManager.codex_connection_observation`. Dönüş sabit allowlist'tir. `Applications.showResult → onDiscoveryChange → App.contextKey` ve lifecycle/config busy değişimi eski sonucu geçersiz kılar. Kurtarma düğmeleri yalnız mevcut önizleme/lifecycle ekranına gider. CodeGraph 16 değişen dosyayı sync etti; graph çalışma zamanı kanıtı sayılmadı.
