# H048 — macOS portu inceleme kaydı

11 Kasım 2026. Bu kayıt korunan sürüm/arşiv alt dilimini kapsar. Ana H048 ve gerçek macOS pencere/paket kabulü açık kalır.

Değişiklik, geç descriptor düzenlemeleri veya 64 işlem kaydı sınırı sonrası mevcut config'i koruyarak çalışmayı sürdürmek için açık bir kabul yolu ekler. Eski dosyalar silinmez. Yalnız uygulamanın typed işlem metadata'sı özel arşive alınır.

Ana ajan Ponytail full/review ve mevcut kalite incelemesini birleştirdi. UI eylemi `ConnectDialog` → `RetainedVersions` → strict native client → async Tauri komutu → `PlanManager` guard/selected scope → sahipli state root → APFS review/archive → yeniden ownership snapshot zinciri kaynakta incelendi. Client kimliği, UUID/hash ve reply korelasyonu, bekleyen işlemde close/başka mutation engeli, inode ve state sahipliği, typed kayıt geçişi, manifest öncesi kopya doğrulaması ve exclusive metadata taşıma kontrol edildi. Mevcut Windows TxF değişmedi; Windows arşiv incelemesi desteklenmiyor sonucu verir.

İncelemede giderilen somut noktalar:

| Önce | Sonra | Neden |
| --- | --- | --- |
| Panel başka bir parent işlemi sürerken kendi eylemini başlatabiliyordu. | Parent disabled prop'u ve synchronous lock sahipliği guard'ı; yalnız kendi aldığı kilidi bırakır. | Arşivlemenin başka işlemin kilidini erken kaldırmasını engeller. |
| Testte gecikme kapısı mount'tan önce kuruluyor, mount bu kapıyı siliyordu. | Kapılar mount reset'inden sonra, render'dan önce kurulur; kullanıcı/proje yanıtları farklı sayılar taşır. | Stale test artık gerçekten bekleyen eski yanıtı yeni kapsamdan ayırır. |
| Fixture, bekletilmeyen archive çağrısında hata dönüyordu. | Normal archive ve bekletilen archive aynı başarı sözleşmesini kullanır; klavye testi callback başarısını da bekler. | Yalnız çağrı sayısını başarılı arşiv gibi sunmaz. |
| Yeni async Tauri komutları bare reply döndürüyordu. | Mevcut komutlarla aynı `Result` dönüşü kullanılır. | Windows derlemesinde görülen gerçek macro/lifetime hatasını düzeltir. |
| Metadata kopyaları oluşturulduktan sonra son hash kontrolü yoktu. | Manifestten önce tüm kopyalar ve yeniden alınan görünüm doğrulanır. | Bozuk kopya tamamlanmış arşiv olarak indekslenmez. |

Son kabul: macOS 15.8.2 ARM64 üzerinde 34 test ve kilitli Tauri build; 4 doğrudan ignored yardımcı ilgili testlerde çağrıldı. Windows filtreleri 72/33/38 test koşumu, 2 opt-in ignored; filtreler örtüşebilir. Frontend 210 test/build ve düzeltilmiş izole Edge koşusu 5/5 geçti. 275 kaynak girdisi adayla ve native önce/sonra fingerprint'i eşleşti. [Makine kanıtı](../proofs/macos-retained-versions.json).

Kalan yayın sınırları: gerçek kurulu istemci keşfi/picker/native pencere, paket yaşam döngüsü ve canlı sağlayıcı yolu bu fixture'larda sınanmadı. Arşiv config dosyalarını küçültmez; eski inode'lar istemci klasöründe kalır. Otomatik temizleme veya fiziksel güç kaybı garantisi yoktur. Yeniden açılış manifestin yapısını doğrular; her işlemde bütün eski arşiv kopyaları yeniden hash'lenmez. Tam yerel kalite kapısı ana H048'in son adayına aittir.

Karar: **Bu alt dilim kabul edildi. Ana görev açık.** Geliştirme token tasarrufu ölçülmedi.
