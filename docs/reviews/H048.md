# H048 — macOS port review

11 November 2026. This review covers retained versions and archiving. At this checkpoint, the main H048 task and native window and package acceptance remained open.

The new action lets the user explicitly continue with the current config. It applies after later descriptor edits or at the limit of 64 transaction records. It retains the old files and archives only app-owned typed operation metadata.

The lead agent combined the full Ponytail implementation/review guidance with the existing quality review. The source review followed `ConnectDialog` → `RetainedVersions` → strict native client → async Tauri command → `PlanManager` guard/selected scope → owned state root → APFS review/archive → reopened ownership snapshot. The review checked client identity and UUID/hash/reply correlation. It checked close and other-mutation blocks during pending work. It also checked inode and state ownership, typed record transitions, pre-manifest copy checks, and exclusive metadata moves. The existing Windows TxF path did not change. The Windows archive review reports unsupported.

The review resolved these issues.

| Before | After | Why |
| --- | --- | --- |
| The panel could start its own action while a parent operation was active. | A parent disabled prop and synchronous lock-ownership guard. The panel releases only a lock it acquired. | This stops archiving from releasing another operation's lock early. |
| The test set a delay gate before mount, and mount cleared it. | Tests set gates after mount reset and before render. User and project replies use different counts. | The stale test now separates an actual pending old reply from the new scope. |
| The fixture returned an error for an archive call that was not delayed. | Normal and delayed archive calls use the same success contract. The keyboard test also waits for callback success. | A call count alone cannot appear as a successful archive. |
| New async Tauri commands returned bare replies. | They now use the same `Result` return type as existing commands. | This fixes the real macro/lifetime build error found on Windows. |
| Copies had no final hash check after creation. | The code checks every copy and the reread view before it writes the manifest. | A corrupt copy does not enter the archive index as complete. |
