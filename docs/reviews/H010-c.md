Ürün kaynağı, dağıtım veya genel istemci ayarı değişmez. [Kanıt](../proofs/opencode-subagents.md), [programatik kabul](../proofs/opencode-subagents.json).

Parent/child ataması gerçek task metadata'sı ve export ile doğrulanır; yalnız model adı veya fixture prompt'u yeterli değildir.

2. Responses kullanıcı blokları `input_text` taşır; tool text okuyucusunu bunlara uygulamak gerçek turu yanlış reddetti (`tests/fixtures/opencode/subagent_fixture.py:31`). Kullanıcı bloğu kendi dar text/input_text şemasıyla çözümlenir; image/bozuk blok negatif testle reddedilir.
3. Server-side CCR zarfında `original_item_count` vardır; iki alanlı MCP zarfına eşitlemek gerçek, eksiksiz sonucu yanlış reddetti (`tests/fixtures/opencode/subagent_fixture.py:60`). Pinned paket kaynağı kontrol edilerek Responses'ın üç alanı/tam sayı sayacı doğrulanır; hash ve özgün içerik birebir kalır. Kısmi içerik metadata eklense de negatif testte başarısızdır.
