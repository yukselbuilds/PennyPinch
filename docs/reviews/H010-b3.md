# H010-b3 değişiklik incelemesi

14 Kasım 2026. Ana ajan, Ponytail full/review ve Emil/Graphite görsel incelemesini tek kabulde yürüttü. Auth/rota, süreç ve kalıcı kayıt sınırları nedeniyle uygulamayı ana ajan üstlendi; yeni çalışan/model/bağımlılık veya global ayar yok. Bu, bütün depo denetimi değildir.

**Sonuç:** Windows 10 yerel ürün retrieval diliminde açık engelleyici bulgu yok. Gerçek sağlayıcı, alt ajan ve diğer OS kabulü bundan türetilmez; ana H010 açık. [Kanıt ve sınırlar](../proofs/opencode-retrieval.md), [programatik sonuç](../proofs/opencode-retrieval.json).

İncelenen bağlı akış: `ConnectDialog` → strict plan decoder → `PlanManager`/native runtime binding → mevcut JSONC span writer ve atomik config/ownership transaction → kaydedilmiş kullanıcı ayarıyla gerçek CLI → paketli MCP köprüsü → aynı kullanıcıya ait GUI ingress/motor → CCR tam içerik → normal Undo/kaldırma. Renderer'a çalıştırılabilir komut verilmez; public plan yalnız bounded retrieval değişiklik türünü taşır. Önizleme payload'ı doğrular, engine workspace/config state'i oluşturmaz. Runtime startup köprü dosyasına gereksiz bağımlı değildir; köprü kurulumunda pin kontrol edilir.

Soket sahipliği uygulama baytlarından önce PID/image/same-user SID ile denetlenir. Serbest URL/path/shell alınmaz; MCP ve HTTP içerik/timeout sınırları vardır. Varsayılan yük tek kullanıcı ve birkaç yerel istemcidir; bu sınırlı koşular stres/uzun süreli performans kabulü değildir. Duraklatılmış geçmiş CCR açık kalır; tam stop güvenli araç hatası verir. Runtime restart aynı endpoint ve geçerli cache gerektirir; geçmişin her koşulda sonsuza kadar korunacağı iddia edilmez.

## Arayüz incelemesi

Gerçek native pencerede Preview/Apply, iptal, çakışma, yeniden açılış ve Undo tıklandı; ekran görüntüsüyle hiyerarşi incelendi. Diğer istemcilerin mevcut bağlantı yolu korundu. Kullanıcıdan test tıklaması istenmedi.

| Before | After | Why |
| --- | --- | --- |
| OpenCode bağlantısı endpoint değişikliğini tek eylemle uygular; ürün retrieval kurulumu yoktur. | Önizle → görünür yerel retrieval açıklaması → Uygula. | Kullanıcı yeni yerel aracı ve kapsamı yazımdan önce görür. |
| Etkin kayıtta yeniden Bağlan eylemi ve ayrıntılar ana akışı kalabalıklaştırabilir. | Etkin OpenCode kaydında Kaldır korunur; MCP çatışması Advanced dışında görünür. | Tek belirgin sonraki eylem ve anlaşılır hata; ek ayar paneli gerekmez. |

Paket manifesti, binary, kaynak ve test araçlarının önce/sonra fingerprint'leri programatik karşılaştırıldı. Sırf kapanış belgeleri için ürün kapıları yeniden çalıştırılmadı. CodeGraph keşif içindi; runtime PASS veya geliştirme token tasarrufu sayılmadı.
