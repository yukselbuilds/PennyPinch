# H033 — Export review

8 November 2026. The lead agent performed the Ponytail acceptance review. The app saves the selected period summary or a sanitized diagnostics report to a new file through native Save As. The report uses the measurement capture already shown in Overview. A later query cannot change the totals in the report. The review assumed one local app, an Overview poll every 5 seconds, and one export at a time.

The review followed `Overview → ExportButton → exportReport client → export_report → ReportManager.begin → Job.render/save → COM Save As → writer`. It also checked `get_overview_snapshot → ReportManager.remember` and `confirm_desktop_exit → Lifecycle → ReportManager.hold_for_exit → PlanManager.hold_for_exit`.

The review checked pinned parent directories, rename through the open handle, and the path decoder shared by the existing file and folder pickers. The team synced 11 files in CodeGraph after the source and index changes. The graph served as discovery. Test and IPC results came from separate checks.

| Before | After | Why |
| --- | --- | --- |
| Period information was available only on screen. | One menu saves JSON, locale-specific CSV, or diagnostics JSON. | The menu follows the existing Graphite hierarchy and uses the current screen. |
| A new query could export different measurements from those shown. | The native cache holds up to 8 displayed aggregate captures by UUID. The job clones the capture before it opens the picker. | The file's percentage, amount, and scope belong to the same capture. |
| The full PeriodMetrics value contains raw basis, attribution, and identity metadata. | The report allowlist selects only totals, coverage, and collection fields. | Diagnostics and CSV exclude raw content and personal paths. |
| The first worker request included schema_version outside the contract. | The client in `src/lib/exportReport.ts` sends only the four fields in the fixed request contract. | The native deny_unknown_fields rule would reject the original request. The lead verified the fix with the same client test. |
| The worker's first version cleared the result after each snapshot. | The result remains until a new export starts or the component unmounts. | The normal 5-second poll preserves the save or error message. |

The writer opens a staging file with `create_new`. It syncs the data before it renames the file to the target through the same open handle. An existing or newly created target stays intact. A pinned parent and a handle that denies other writes and deletion protect the staging path. Error cleanup uses the same handle.

The report limit is 262,144 bytes. The native side supplies the path, filename, and token totals. The change uses the existing IPC error and UUID mapping and the existing revision and config ownership rules. It preserves the model, authentication, routing, statistics, and beacon contracts.

The exit check proceeds through Lifecycle, ReportManager, and the config barrier, in that order. The app releases the export lock before it opens the picker. A pending export blocks exit. A failed config exit attempt leaves export available. The RAII job guard releases the job on cancellation or error.

The review checked pending state, an absent snapshot, and an unavailable command in browser mode. It covered expired capture, existing target, write and path errors, and a late reply after unmount.

In `src/features/overview/ExportButton.tsx`, the cancel result can also include the `outcome.stale` note. The cancel message is accurate. The extra capture explanation can make it longer than necessary. A future copy change could limit the note to a saved result. The review treated this as optional wording work.

The gate passed 161 frontend tests and 371 Rust tests and ignored 8 opt-in tests. Formatting and builds passed on the same candidate. The UI fixture passed 20 combinations and 6 behavior groups. The native run produced 3 files and passed 18 checks for the files and Cancel. The 16 aggregate checks matched 180 source and config inputs. [Evidence](../proofs/export.md)

A separate recovery resolved the QA cleanup problem with an open SQLite handle. The app closed, and the state and Run value matched the baseline. The native exit code remained unknown. The lead checked the evidence directly.

**Decision. The review accepted local H033 at 32/51.** Windows 11, other operating systems, installation, live providers, sustained load, and real disk exhaustion needed separate evidence. The native English dialog also remained untested. H034 had yet to start.
