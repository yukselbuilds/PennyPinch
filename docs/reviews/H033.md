# H033 değişiklik incelemesi

8 Kasım 2026; ana ajan Ponytail kabul incelemesi. Seçili dönem özeti ve ayıklanmış tanı raporu native Save As ile yeni dosyaya kaydedilir. Genel bakıştaki ölçüm anı dosyaya taşınır; yeni sorgunun başka toplam getirmesine izin verilmez. Tek yerel uygulama, 5s overview poll ve aynı anda tek export yükü varsayıldı.

Bağlı akış okundu: `Overview → ExportButton → exportReport client → export_report → ReportManager.begin → Job.render/save → COM Save As → writer`; `get_overview_snapshot → ReportManager.remember`; `confirm_desktop_exit → Lifecycle → ReportManager.hold_for_exit → PlanManager.hold_for_exit`. Parent dizin pin'leri, Handle rename ve mevcut file/folder picker'ların ortak yol decoder'ı incelendi. Source/index değişiminden sonra CodeGraph11 dosyayı sync etti; graph test veya IPC kanıtı sayılmadı.

| Before | After | Why |
| --- | --- | --- |
| Dönem bilgisi yalnız ekranda görülebiliyordu. | Tek menüden JSON/locale CSV veya tanı JSON kaydedilir. | Menü mevcut Graphite hiyerarşisini korur; yeni ayar ekranı eklemez. |
| Yeni export özelliğinde yeniden sorgulama farklı bir ölçüm anı üretebilirdi. | Gösterilmiş native aggregate capture'ı UUID ile en fazla8 kayıt; job picker öncesi clone alır. | Dosyadaki yüzde, miktar ve kapsam aynı görüntüye ait olmalı. |
| PeriodMetrics bütünü raw basis/attribution ve kimlik metadata'sı içerir. | Report allowlist yalnız toplam/kapsam/koleksiyon alanlarını seçer. | Tanı veya CSV'ye ham içerik/kişisel yol taşınmamalı. |
| Worker'ın ilk request'i sözleşmede olmayan schema_version içeriyordu. | `src/lib/exportReport.ts` yalnız dondurulmuş dört request alanını yollar. | Native deny_unknown_fields isteği reddederdi; root aynı client testiyle düzeltmeyi doğruladı. |
| Worker'ın ilk outcome reset'i her yeni snapshot'ta bildirimi siliyordu. | Yeni export başlayana veya unmount'a kadar sonuç korunur. | Normal5s poll kullanıcıya verilen hata/kaydetme bilgisini silmemeli. |

Writer yalnız create_new staging açar, sync sonrası açık handle'ı hedefe taşır; replace kapalıdır. Başka dosya görünürse korunur. Parent pin ve no-foreign-write/delete handle'ı staging yolunun değiştirilmesini engeller; hata cleanup'ı aynı handle'ı kullanır. Rapor en fazla262144 bayt; frontend path, filename veya token toplamı yollayamaz. Mevcut IPC hata/UUID eşlemesi, revision/config sahipliği, model/auth/rota ve stats/beacon semantiği değişmez.

Exit denetimi Lifecycle → ReportManager → config bariyeri sırasındadır; export lock'u picker sırasında tutulmaz. Pending export çıkışı reddeder, başarısız config exit denemesi export'u kalıcı kilitlemez. Cancel/error'da RAII job guard bırakılır. UI pending, null snapshot, browser unavailable, expired/exists/write/path hatası ve unmount son yanıtı incelendi.

İsteğe bağlı metin gözlemi: `src/features/overview/ExportButton.tsx` outcome.stale notunu iptal sonucuna da ekliyor. Açık iptal iletisi doğru, ancak ek ölçüm-anı açıklaması gereksiz uzayabiliyor; ileride yalnız saved sonucuna sınırlandırılabilir. Bu kozmetik öneri yeni düzeltme turu veya açık kabul engeli yapılmadı.
