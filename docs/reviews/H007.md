## Kabul edilen dilim

H007-b, Windows 10 geliştirme hostunda pinned 0.41.0 proxy üzerinden gerçek HTTP sıkıştırma/retrieval ve TTL kanıtıdır. Yerel upstream, giden araç çıktısındaki CCR hash'ini görür; aynı motorun public retrieval yanıtı özgün içeriğe eşittir. Hazır sıkıştırılmış fixture motor çıktısı gibi sunulmaz. 153.599 → 106 UTF-8 bayt sonucu token tasarrufu sayılmaz. Komut, ortam ve kaynak fingerprint'leri [kanıtta](../proofs/protocol.md).

Koordinatör runner `aa3c9dfe38386f84ee0c15e2b835cd1d3e127df134ca49ba088df54933acc771`, fixture `d2e8dfa09137b0b5657735edb2beb1facdb55a38cef906f6668fbce5169fbe8a`, değişmeyen H006 helper ve manifest hash'lerini karşılaştırdı. Kaynak/config/araç zinciri için geçersizleşme nedeni olmadığından başarılı B komutu yeniden çalıştırılmadı.

- Anthropic unknown-last sorunu H007-a'da kapandı: pinned startup shim, explicit marker dahil beş yerleşimde gerçek HTTP regression ve iki mismatch guard testi geçti. Koordinatör runner/shim/test/pinned-source hash'lerini eşleştirdi; geçerli testler tekrarlanmadı. Uyarlama henüz üretim runtime/paketine taşınmadı; H014/H037 bunu sahiplenmelidir.
- Kısa/history Read/numeric örneklerinin kanıt açığı H007-c ile kapandı: son gözlemdeki 60.900 bayt kaynak ve açık tool korumasıyla 59.219 bayt sayısal metin birebir. Sayısal koruma, eşleşen araç/şekil kapsamındadır. Son C runner hash'i kanıtla eşleştirildi; geçerli test tekrarlanmadı.
- Input ve stream alanlarının korunması, provider auth uyumluluğu veya gerçek istemci entegrasyonu anlamına gelmez. H008–H010 ayrı kanıt ister.
- Şu an SSE kontrolleri yanıt tamamlandıktan sonra event sırası/payload bütünlüğünü sınar. İlk event'in upstream tamamlanmadan ulaşmasını kanıtlayan artımlı teslim testi ve gerçek tool döngüsü H008 istemci kanıtında ayrıca gerekir.

## İncelenen sınırlar

Fixture loopback'e bağlanır, sentetik auth kullanır ve capture'ları bellekte tutar. Readiness, subprocess/listener PID sahipliği ve pinned sürüm kontrol edilir. Süreç/port/geçici state temizliği başarısızsa runner artık PASS dönmez. Etkin cache/coding/output-shaper ayarı `/health` üzerinden okunur; model router'ın explicit kapalı değeri source/config fingerprint'ine dahildir.

Tüm başarılar Windows 10 hostuna aittir. Windows 11, temiz ortam, gerçek Codex/Claude/OpenCode kimlik doğrulaması ve native Tauri yaşam döngüsü henüz bu kanıtın parçası değildir.
