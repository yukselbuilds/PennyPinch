# H009 ana kabul incelemesi

15 Kasım 2026. Ana ajan mevcut H009-a/H009-b, H020, H022, Karar 008, TASKS kabulü/K2 ve güncel Claude bağlantı/katalog yolunu birlikte inceledi. Ponytail full/review mevcut incelemeyle uygulandı. Değişiklik mevcut kanıtın doğru kapsamla ana kabule bağlanmasıdır.

İncelenen bağlantı yolu native kapsam seçimi → plan yöneticisi → atomik Apply/sahiplik → sabit ingress → motor → gerçek CLI → yerel Anthropic SSE ve conflict-preserving Undo'dur. Claude planı yalnız `env.ANTHROPIC_BASE_URL` hedefler, sürüm kapısı 2.1.158'dir. Model/efor/auth alanları değişmez. Bildirilen alternatif Bedrock/Vertex/Foundry rotaları desteklenmiş sayılmaz. H022 remembered context/transactional first use, eski H020 sınırlamasının yerine geçer; başka oturumun ayar benimsemesi çıkarılmaz.

Katalog bulgusu giderildi: araç/CCR sonucu eksikken yalnız ilk tools-off yüzey gösteriliyordu. Ayrı izole MCP/server-side CCR kabiliyeti eklendi. Thinking değeri yalnız bu yeni profil için kanıtlıdır; eski tools-off durumunun `not_tested` kaydı korunur. Native UI tools-off kaydı, araçlı native UI kabulüne yükseltilmedi. H022'nin eksik ebeveyn ve hatırlanan proje sonucu eklendi; OAuth/alt ajan ve diğer bilinmeyen birleşimler aynı durumda kaldı.

Ana kapanış, canlı hesap veya bütün mümkün model/yüzey birleşimlerini zorunlu kılan yeni bir kabul üretmez. H009 hesap/yetki yoksa sınır kaydını, K2 deneysel birleşimleri açıkça tanımlar. Modelden bağımsız endpoint tasarımı tek başına gerçek alt ajan rotası kanıtı değildir. Kullanıcının Claude girişini ertelemesi korunur. H020 ve H009-b ayrı UI/araç profilleridir; birlikte tek araçlı native ürün koşusu diye sunulmaz.

Katalog uygulamaya gömülü olduğundan son adayda 222 Node/462 Rust, 19 ignored, fmt/frontend/embedded build kapısı bir kez geçti. Kanonik kaynaklar, tutulan sonuç referansları, önce/sonra çalışma alanı/araç/OS fingerprint'leri [ana JSON](../proofs/claude-acceptance.json) ile bağlıdır. Tarihsel UI snapshot'ları kendi adaylarını kanıtlar; güncel kaynak kapısı ayrı gösterilir. Kabulü engelleyen açık bulgu yok. İncelenmeyen canlı hesap/sağlayıcı, genel MCP/hooks/plugins, Claude Desktop/eklenti, alt ajan ve diğer OS kapsamı [ana kabulde](../proofs/claude-acceptance.md) açıkça kayıtlıdır.
