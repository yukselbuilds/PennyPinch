# H024 — ana ajan kabul incelemesi

4 Kasım 2026. Kapsam yeni kalıcı metrik deposu, ortak normalizasyon merge/validation, ağırlıklı sorgu ve native IPC. Beklenen kullanım tek masaüstü kullanıcısı;100.000 event/128MiB sınırına kadar veri yapıları incelendi, bu yükte performans ölçülmedi. Ponytail-review ile mevcut kalite incelemesi birleştirildi; tüm depo audit'i tekrarlanmadı.

## İncelenen akış

H023 `normalize`/`project_headroom_041` → `MetricsStore::ingest_projection` → input/slot doğrulaması → mevcut directory pin'leri ve dosya hardlink/reparse kontrolü → SQLite transaction/merge/upsert → yerel takvim/retention filtresi → aynı temel gruplarında ağırlıklı toplam. Renderer yalnız `get_metrics_summary` okuyabilir; async native handler blocking DB işini ayırır. Setup aynı Store klonunda izleme kimliğini tutar. H025 collector/UI bağlantısı henüz yapılmadı; bu sınır TASKS ve contracts'ta açık.

Auth/model/rota ve ownership ayarlarının yazım yolu değiştirilmedi. SQLite bounded metadata alır; parametreli SQL kullanılır, yabancı şema sessiz migrate/overwrite edilmez. Boş sorgu dosya yaratmaz. DB header/transaction ve gerçek ayrı süreç yeniden açılışı incelendi. H023'ün eski karşılaştırılabilirlik güveni yükseltilmedi.

## Kapanan bulgular

- 65 farklı tokenizer grubu sorgulanınca sınırsız ayrıntı native yanıta büyüyebilirdi (`src-tauri/src/metrics/query.rs:103`).64 grup ve omitted_basis_groups ile yanıt sınırlandı; karışık temellerin birleşik yüzdesi null kalır. Regresyon önce FAIL, sonra PASS.
- URN biçimindeki nil UUID parse ediliyor ama düz nil metni karşılaştırmasına takılmıyordu (`src-tauri/src/metrics/store.rs:304`). Canonical non-nil kontrolü eklendi; geçersiz girdi hata cevabına kopyalanmaz. Regresyon önce FAIL, sonra PASS.
- Yeni geçerli-hex event_id ile aynı origin/slot tekrar sunulduğunda ayrı satır kabul edilebilirdi (`src-tauri/src/metrics/normalize.rs:363`). Non-conflict event_id köken/slot hash'iyle tekrar doğrulanır; ikinci kayıtla toplam şişmez. Regresyon önce FAIL, sonra PASS.

Temel/bileşen grupları BTreeMap ile toplanır; O(n²) grup araması yoktur. İnceleme sonrası kozmetik refactor veya yeni ürün kapsamı eklenmedi. Mevcut directory-pin yardımcısı yeniden kullanıldı; JSON dosyasının tüm geçmişini her polling'de yeniden yazan ikinci depolama mekanizması eklenmedi.
