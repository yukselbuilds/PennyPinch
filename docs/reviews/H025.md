# H025 — Lead agent acceptance review

5 November 2026. The lead agent combined Ponytail review with the quality review. The work connects the H024 store to the owned live source and the Graphite Overview screen. The review assumed one desktop user, metadata samples every 5 seconds, and bounded local storage. Sustained performance under load remained unmeasured.

<a name="incelenen-akış"></a>

## Paths reviewed

The runtime actor checks the held process lease, generation, and exact TCP peer. It reads the fixed loopback path `/stats?cached=1` with limits of 2 MiB and 1.5 seconds. The H023 allowlist limits the data. H024 upserts records in a transaction. The local query supplies totals and sparse time buckets for the same period.

Overview calls the read-only `get_overview_snapshot` command. The renderer checks response correlation, numeric values, and period order before it updates the chart and totals. Its access is read-only and local. On exit, the app stops the collector before the runtime closes the processes it owns.

The review checked `main.rs`, `runtime/manager.rs`, `runtime/metrics_read.rs`, `metrics/{normalize,query,store,collector}.rs`, and related tests. It followed the App through the Overview hook, session, and client. It also traced Applications, ConnectDialog, and ConnectionStatus to the existing native plan, ownership, and verification calls. It checked start, stop, stale replies, cancellation, runtime generation changes, persistent history, and error paths. The review verified that Apply, Undo, and the authentication, model, and reasoning settings kept their existing paths.

<a name="kapanan-bulgular"></a>

## Findings fixed

- `runtime/metrics_read.rs:43` expected a hyphenated UUID. The controller supplied a generation ID with 32 hexadecimal characters, which caused `invalid_snapshot`. All initial fixtures used hyphenated text, so the first gate missed the failure. A run with the real engine found it.

  The fix reuses runtime validation. It preserves the wire ID and correlates it with H023 events by canonical UUID value. The actual format failed the regressions before the fix. The 5 reader tests, 4 collector tests, and frontend identity checks then passed.
- The Advanced toggle lock in `Applications.tsx` blocked read-only operations. It also released the lock if the section closed during verification. After the first open, the Advanced content stays mounted. Only active verification holds the parent and App lock. A native read-only rescan and an isolated pending verification fixture checked open, close, and completion. The fixture ran without live verification or model requests.
- A late response could put the old period's values under the new period label. `metricsSession.ts` runs one request at a time and uses an epoch for the period and active state. It combines pending requests into the latest one. It discards responses from earlier periods. An error in the same period leaves the last result marked stale, with the time and reason. Four race and error tests passed.

## Connection and interface

`equivalentInstallations.ts` uses one temporary target for 2 to 4 Codex plans when native verification confirms them and the plans remain valid. The effective scope, fingerprint, endpoint, and effect must match. A similar name or version alone gives no evidence of equivalence. A stale or unavailable selection requires an explicit choice. The real local run found three candidates and asked for a choice when the old selection was unavailable. The tests passed for equivalent plans, different plans, and missing or stale responses.

Connect uses the existing sequence. The app remembers the selection, starts the runtime when needed, creates a fresh Preview, and runs Apply with ownership recorded. Plan comparison is read-only.

Graphite omits the second empty chart when data is absent. Details hold the technical counters. The display distinguishes measured zero, an increase, an unknown value, and an error. The main window controls its own zoom through `set_webview_zoom`. Zoom leaves OS DPI and saved preferences outside its scope.

The collector takes a sample every 5 seconds even outside Overview. The view refreshes the local query. The change requires no new chart, framework, or font dependencies. The Playwright development dependency tests the installed WebView2 without a browser download.

**Decision. The review accepted H025 and found no required fixes remaining.** The gate passed 120 frontend tests and 327 Rust tests. It ignored 5 existing opt-in tests. Build and formatting passed. The native tests passed for collection, stop, restart, and zoom. The checks recorded source, config, tool, environment, and artifact fingerprints in the same steps.
