# H017 — Salt okunur bağlantı önizlemesi incelemesi

21 Ekim2026. Ana ajan inceleme, düzeltme ve son yerel kanıtları kabul etti. Tek GPT-6 Luna xhigh çalışan sıralı uygulama dilimlerini yürüttü; ikinci çalışan açılmadı. **H017 tamamlandı, H018 başlamadı.**

| Boyut | İnceleme sonucu |
| --- | --- |
| Doğruluk | UI eylemi → typed komut → mevcut tek manager çifti → gerçek sınırlı config okuması → planner → strict yanıt yolu incelendi. Bir gerekli endpoint alanı; config bildirimi ile runtime bilinmezliği ayrı. Sürüm/route/override belirsizlikleri engelli taslak; bağlantı başarısı iddia edilmiyor. |
| Güvenlik ve gizlilik | Renderer keyfi yol/URL/port/sır veremiyor. Backend sabit disk/reparse/kimlik/boyut/parse sınırlarını ve yeniden karşılaştırmayı uygular; parent no-share-delete, file no-share-write/delete. Junction, writer/rename, same-bytes replacement/JSONC slot drift ve secret redaction regresyonları var. Sır/raw model/hook komutu state/log/DTO'ya taşınmıyor. |
| Performans ve kaynaklar | Dosya256KiB, parser derinlik/token/node sınırları, tek inflight okuma,64 süreli redakte lease ve5dk TTL. Blocking I/O spawn_blocking'de; otomatik preview veya poll başına okuma yok. Bu kaynak sınırları gerçek latency benchmark'ı sayılmadı. |
| UI ve bakım | Graphite TR/EN ve iki tema; okunur diff/korunma satırları, açık kapsam ve oturum/rota sınırları, disabled Apply. Çoklu seçim, stale reply suppression, expiry/refresh, keyboard trap ve focus restore incelendi. Dar typed view helper ve sabit çeviriler kullanılıyor. |
| Kanıt ve regresyon | Son107 Rust/38 Node PASS,2 opt-in ignored; build/typecheck/format PASS.32 temel+8 dialog/5 fixture akışı ve ayrı gerçek native üç config formatı yolu kabul. Kaynak/config/toolchain/artifact hash'leri birbirine bağlı. |

İnceleme sırasında giderilen bulgular: JSONC AST öncesi derinlik sınırı, Windows READ_ATTRIBUTES-only parent rename varsayımı, fingerprint length framing, missing-file çelişkileri, tek inflight guard'ın hata sonrası bırakılması, exact endpoint etiketleri, eski yanıt korelasyonu ve Tab'ın BODY'ye kaçması. İlk başarısız kontroller PASS olarak kullanılmadı; ilgili dar regresyonlar ve son aday kanıtı korundu.

Bloklayıcı açık bulgu yok. Production build'de testlerin kullandığı `preview_config` adapter'ı için1 dead_code uyarısı var; runtime davranışını etkilemiyor. Yerel native WebView outer dialog'da da scrollbar gösteriyor; başlık/footer ve içeriğin tamamına erişim geçti, responsive/çoklu tema kontrolleri ayrıca statik artifact'te doğrulandı. İkinci işletim sistemi/DPI/installer kabulü bu görev kapsamında yapılmış sayılmadı.
