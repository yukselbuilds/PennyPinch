# H008 güncel Codex düzeltmesi incelemesi

3 Kasım2026; root, Ponytail full/review ve mevcut kalite incelemesini tek kapsamda uyguladı. Ana görev kapatılmadı.

- İncelenen akış: discovery/publisher+version/provenance→strict frontend metadata→PlanManager→config transaction/ownership→Apply/Undo; ConnectionStatus→CodexVerifyManager→selection/file/parent pins→runtime lease/owned ingress→CLI JSONL→strict sonuç decoder'ı. Model/auth/reasoning ve başka istemcilerin version/surface kapıları korunur.
- İncelemede kapananlar: manuel keşif frontend'inin ikinci eski version listesi; Desktop'ın GUI/backend sürümü karışımı; imzalı metadata'sız launcher'ın gerçek GUI'yi gizlemesi; registered package'ın uzun PATH bütçesinde kaybolması; debug verifier'ın CodeGraph checkout config'ine takılması. Davranışa bağlı RED/gerçek yerel kabul eklendi. Eski workspace unit testi yeni sözleşmeye uyarlandı; mixed-separator fixture düzeltildi.
- Güvenlik: yalnız zinciri/publisher'ı doğrulanmış program version komutuyla yürütülür; legacy tam hashler korunur. Ağ/device/reparse çözümü bounded; dosya kimliği/byte digest ve no-write/delete handle korunur. Ortak OwnedJob, önceki verifier sahiplik/kapanış davranışını taşır. Certificate cache yalnız offline kontrol kapsamındadır. Renderer paths/auth seçmez; değişen seçimin/config'in/lease'in başarı üretmesi engellenir.
- Yük varsayımı: tek kullanıcı desktop taraması;64 PATH/512 deneme ve16 package/version sınırları korunur. Debug sha2 optimize edildi; süreler tek host/çalışma durumuna aittir, genel performans veya token benchmark'ı değildir. Kaynak değişimi için CodeGraph sync yapıldı; dinamik IPC/tarayıcı/istemci trafiği graph PASS sayılmadı.
- Kabul:289 Rust +98 frontend, fmt/embedded build; iki kurulu binary/config opt-in; gerçek normal hesapla native UI verifier sonucu. [Kanıt ve sınırlamalar](../proofs/codex-current.md). Ekran sonucu, genel trafik doğrulanmış gibi gösterilmiyor; yalnız yeni CLI yanıtı/iki ek bildirim ayrımı doğru.
- Kalan: iki bildirimin nedeni, canlı Desktop/alt ajan ve genel auth/WS. Fixture count/time-window eşleşmesi exact request korelasyonu değildir. UI helper fingerprint bracket'ı vardır; worker engine harness kendi pre-hash'i eksiktir. Kullanıcının eski H022/H023, AGENTS/WORKFLOW ve diğer dirty değişiklikleri korundu; commit/push/CI/release yok. Ölçülmüş geliştirme token tasarrufu yok.
- Kapanış kanıtı ayrı tutuldu: uzun yanıt QA run'ı deadline/owned Job cleanup ile bitti; yanıt sonrası normal kapanış kabul edilmedi. Yeni kısa/no-model Ready→WM_CLOSE run'ı exit0/config+prefs aynı/owned listener kalmadı olarak geçti. Bu sonuçlar birbirinin yerine kullanılmaz; sonraki H008 adımı bu gözlemi de sınıflandırır.
- Ek salt okunur runtime/verifier/exit incelemesi belirli deadlock bulmadı. Debug phase metadata'sından sonra yeni kısa gerçek yanıt→kapanış da clean/exit0~879ms geçti (`a6bbd355-db52-4020-967e-2a05dbae4716`); source field sınırlamaları ve release davranışı değiştirilmedi. Bu bir race kök nedeninin bulunması değildir. Son tam native kapı289 PASS/5 ignored ve fmt/build PASS olarak güncellendi; eski başarısız kapanış gözlemleri takipte kalır.
