27 October 2026. **Decision. The review accepted H022 and found no open blockers.** The starting commit was `83f77bc`. The candidate was the local working tree. The lead agent applied Ponytail full and review in one pass under the shared acceptance criteria.

## Findings fixed during review

1. The app could create the root before it checked a changed ChoiceStore boundary identity. This could create a file outside the user's boundary. The fix moved the check in `src-tauri/src/state/choices.rs:243` before the write. It also rejects reparse points on the original boundary path before canonicalization. The focused regressions and final gate passed.
2. The picker could open the Shell's most recently used location when it found no safe start folder. The path in `src-tauri/src/integrations/picker.rs:168` now requires a safe hint and SetFolder. It returns a fixed unavailable result otherwise. This prevents an unrelated or invalid start folder.
3. Parallel ownership reads for the simple cards could return busy from the shared native guard. `src/features/integrations/Applications.tsx` now reads the three clients in sequence. Advanced, scan, and dialog actions use the same boundary for changes. Native observation showed no false missing status.
