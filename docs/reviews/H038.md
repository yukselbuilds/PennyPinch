# H038 — Lead agent review

9 November 2026. Ponytail Review covered the new uninstall path and normal app entry. It also covered config and ownership operations for the three adapters, the autostart record, and the NSIS template. Expected load was one user, multiple Headroom instances in one profile, and another process that can change client settings at the same time.

The UI disconnect action and uninstaller use the same `PlanManager::undo_connection` operation. For each client, the config and ownership record update in one NTFS transaction. If one client fails, the system keeps earlier successful undos and retries only active records. An endpoint change by the user or inaccessible config blocks data deletion.

The uninstaller uses file sharing to exclude open Headroom instances for the same user. It removes local data only if the user selects deletion and the app has undone the connections. It gets the root from the Windows local application data directory and the compiled application ID. It checks reparse points.

It removes the startup record through the existing protected path only when the installed EXE command matches exactly. The team removed the Tauri template's unconditional Run-value deletion and broad cleanup of two directories.

Four focused tests, 392 Rust tests, and real UI/uninstaller scenarios on the installed QA candidate passed. A failed Undo commit kept config and ownership together in the existing regression test. A lock on the history file made the uninstaller show an error and keep installation files. The test released the lock, then retried and completed. The test preserved model, reasoning, comments, and all three external client configs. All 212 inputs matched at acceptance. [Evidence](../proofs/uninstall.json), [local validation](../validation/uninstall.md).

No critical finding remains open in the reviewed local scope. The review accepted H038. The team tracks the Windows 10 result with the QA identity separately from production identity and Windows 11/clean-environment checks. If data deletion fails in part, the uninstaller does not restore app data that it already deleted. H042 covers update and signature acceptance.
