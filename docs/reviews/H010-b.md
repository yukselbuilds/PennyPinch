# H010-b koşullu teknik incelemesi

14 Kasım 2026. Ana ajan, Ponytail full/review ve mevcut kalite incelemesi. H010-b2 test profili koşullu kabul edildi; varsayılan ürün entegrasyonu ve ana H010 açık, toplam 42/54.

Gerçek OpenCode 1.19.3 binary hash'i doğrulandı. H021'in Chat/OpenAI Responses profilleri ayrı, izole inline config/HOME/XDG/ProgramData/workspace ve sahte API key ile çalıştı. Varsayılan araçlar/diğer MCP'ler engelli; yalnız sabit fixture aracı ve açıkça tanımlanmış retrieval aracı izinliydi. Kullanıcının auth/config dosyası veya modeli değiştirilmedi. H009'un sabit MCP veri sunucusu ve bounded output okuyucusu, H041'in controller/helper altyapısı tekrar yazılmadan kullanıldı.

İncelenen gerçek akış: CLI → stdio MCP → native işlev sonucu → loopback test ingress → Headroom sıkıştırma → upstream talebi → CCR → ikinci araç → final → normal kapanış. Giriş gözlemcisi özgün log/wire çıktısını tutarlı görür; asıl geri alınan wire string'i de birebir aynı olmalıdır. Testlerde hiçbir serbest URL/path/shell native retrieval aracı tarafından alınmaz; hash doğrulaması ve sabit sahip engine portu vardır. Protokol biçim dönüşümü yalnız fixture doğrulaması/yanıt üretimidir, kullanıcı isteğini Chat'ten Responses'a değiştirmez.

İki ilk endpoint-only profil başarısız kaldı. Kaynak incelemesi streaming Chat'in otomatik CCR enjeksiyonunu bilerek yapmadığını; Responses'ın ise zaten tanımlanmış aracı buffered continuation ile işlediğini doğruladı. Bunlar fixture varsayımı düzeltilerek varsayılan ürün başarısına çevrilmedi. Sonraki koşullarda test konfigürasyonuna dar MCP köprüsü açıkça eklendi; uygulamanın mevcut Bağlan eylemi bunu yapmış sayılmadı.

Son iki gerçek koşuda Chat 4 native/4 upstream mesajı ve native MCP retrieval, Responses 3 native/4 upstream mesajı ve server-side retrieval tamamlandı. Call ID/model/auth, 14.999→103 bayt blok, byte/SHA eşit geri alma, ikinci araç/final/exit0 ve graceful motor/port temizliği geçti. Beş odaklı test ve üç sınır kontrolü yanlış kimlik/hash/içerik/model/reasoning kaymasını, keyfi URL/araç denemesini reddeder; Chat'in pinned streaming policy'sinin değiştirilmediğini doğrular. [Programatik sonuç](../proofs/opencode-tools.json).

Ürün kodu ve eski kalite kapısının 325 girdisi/araçları aynı kaldı; 441 Rust/221 Node/fmt/build kanıtı ilgili kapsamda yeniden kullanıldı. Başarılı kontroller sırf bu yeni fixture için tekrarlanmadı. Raw CLI/gövde/hata raporu kalıcılaştırılmadı; yalnız metadata/hash/sonuç tutuldu. İnceleme bütün depo denetimi veya yeni ürün MCP güvenlik kabulü değildir.
