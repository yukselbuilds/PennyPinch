# H010-j incelemesi

Ana ajan paketli süreç, rota ve geri alma sahipliği nedeniyle uygulamayı üstlendi. Headroom UI → kalıcı kullanıcı ayarı → OpenCode Desktop GUI → paketli servis → Headroom motoru → MCP/Responses → GUI final yolu incelendi. Ürün adaptörü mevcut CLI bağlantısını kullandı.

- Kurucu digest'i ve yayın checksum'u doğrulandı. Paketli CLI'nin staged kopyası, gerçek servis PID'sinden bulunan dosyayla eşleşti. GUI ve servis ayrı test profilinde kaldı.
- Yalnız servis ortamına verilen sentetik anahtar ile doğru süreçten gelen model trafiği doğrulandı. Tek kök oturumun kayıtlı modeli, mesajı, araç sırası ve finali gerçek GUI çıktısıyla eşleşti.
- Normal quit gerçek Electron ana PID'sinin process handle'ından exit 0 olarak görüldü. Bağımsız servis daha sonra durduruldu. Windows'taki test taşıyıcısının süresini gerçek uygulamanın çıkışıyla karıştıran önceki koşu kabul edilmedi.
- Geçici protokol kaydının önce bulunmadığı ve son sahibinin test executable'ı olduğu denetlendi. Normal Kaldır özgün config'i döndürdü. Önceki testlerin temizliği ayrıca kontrol edildi. Bir Uygula hatası yeniden üretilemedi ve nedeni bilinmiyor.
- Katalog, CLI kurulumu üzerinden Desktop turunu Windows 10/2.3.0/sentetik koşulla sınırlar. Desktop-only keşif ve canlı auth açık. [Kanonik kanıt](../proofs/opencode-v2-desktop.json)
