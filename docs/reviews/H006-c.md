# H006-c incelemesi

15 Kasım 2026. Ana ajan, Ponytail full/review ve mevcut kalite incelemesini birlikte uyguladı. Kapsam tek kullanıcıya ait yerel Windows 10 test ailesidir. Ürün davranışı değişmez, gerçek paketli GUI sahibinin kaybı ve aynı profilde normal yeniden açılış için benchmark eklenir.

İncelenen bağlı yol native Başlat düğmesi → mevcut Tauri komutu/manager → manifest doğrulaması → controller/helper/engine → Ready/listener sahipliği → yalnız GUI'nin eldeki Child handle'ını sonlandırma → OS süreç/port kapanışı → aynı kimlikle yeniden açılış → Başlat/Durdur/normal Çıkış'tır. Runtime'ın üretim Job/EOF davranışı değiştirilmedi. Başlangıçtaki spawn/Job ataması aralığı bu hazır durum deneyinin dışında kaldı.

Gözlemci kendisini dış Job'a atamaz. GUI, mevcut Child handle'ı üzerinden bu Job'a atanır. Motor süreçleri Job üyeliği ve paketli Python görüntü yolu ile seçilir, liveness ölçümü boyunca açık process handle'ları tutulur. PID'ye göre yabancı süreç kapatma yoktur. Dış Job açıkken süreçler/portlar kapandığı ve Job boşaldığı doğrulanmadan başarı yazılamaz. Her iki kolda yabancı listener tanık baytlarını korur. Test hiçbir istemci bağlantısı veya model isteği üretmez.

İlk denemedeki yanlış TCP tablo sabiti giderildi. Son sürücü pinned runtime sabitlerini kullanır. Başarısız deneme ve state byte-exact korunur, cleanup başarısı ürün başarısına sayılmaz. Gereksiz hash geçişleri kaldırıldı; tam içerik hash'i native başlangıç/son taramalarında korunur. Derlemede kullanılan sürücünün özgün hash'i ayrı saklanır. Değişen test gözlemcisiyle ürün/payload/UI/derleme girdisi karıştırılmaz.

Son native aday geçti. 57,429ms süreç ve 58,299ms port kapanışı, 5000ms eşik içindedir. Yeniden açılış Stopped, korunmuş endpoint, farklı generation, Ready/Stop ve normal GUI exit 0 doğrulandı. İki kolda sahipli süreç/port 0 ve model isteği 0. 22.689 girdi/araç/OS eşleşmesi [kanonik JSON](../proofs/windows-gui-crash.json) ile bağlıdır. Değişmeyen ürünün 222 Node/462 Rust/19 ignored/fmt/frontend/embedded build kapısı tekrar çalıştırılmadı.

Kabulü engelleyen açık bulgu yok. Temiz OS, Windows 11, Job ataması öncesi yarış, aktif stream/CCR ve genel kararlılık incelenmedi. Yeni UI tasarımı, sağlayıcı doğrulaması, maliyet/tasarruf ölçümü, installer veya yayın kabulü verilmedi. H006-c yerel alt dilimi kapanır, ana H006 ve 45/54 korunur.
