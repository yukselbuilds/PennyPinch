## Findings fixed

- **Serde unit model filter.** The first unit `any` variant in `activity.rs` accepted extra fields. The fix uses an empty struct variant. The regression checks that the native query rejects unexpected filter fields.
- **Incorrect scope label.** The first `Activity.tsx` view described records without a placeable time as unmatched agents or clients. The corrected label uses the store's meaning. It describes time uncertainty and the evidence available for the period.
- **Model label validation.** The shared Rust and TypeScript policy also rejects absolute Unix paths. The exact-match UI filter applies the same validator before sending the label.
- **Narrow layout and dialog.** The row can wrap to the available width after the fix removes fixed minimum columns. A late close event cannot clear a new selection. The review checked native keyboard and focus behavior. It also checked a late detail response.

The gate passed 133 frontend tests and 344 Rust tests. It ignored 5 existing opt-in tests. Formatting, builds, and the embedded debug executable passed. Native checks passed for metadata, period selection, not found, validation, and collection from the owned source.
