# H023 review

3 November 2026. **Decision. The review accepted the normalization and adapter scope and found no open blockers.** The lead agent applied Ponytail full, Ponytail review, and code-review-and-quality to the same change. The normalizer calculates a signed difference and percentage for a pair with explicit evidence. The adapter projects metadata without content from pinned Headroom 0.41.0. It keeps conflicting values unknown. An overlap between a message and the full input causes a conflict. Other measurement layers stay separate from the main input count.

The review checked limits for size, record count, numeric values, time, and UUIDs. It also checked fixed errors without payloads and the `O(n log n)` transform. No performance benchmark ran.

## Finding fixed

**P2. A third conflicting record could retain an uncertain time and basis.** The issue was in `normalize.rs:304`. The regression is in `normalize_tests.rs:181`. The first two observations of one event reported different counts. The third reported a different UTC day. The amount became unknown, but the first time and basis could remain. A future period query could assign the record to the wrong day and basis.

The new test reproduced the failure first. The fix marks conflicting readings as unverified and sets their values to null. It also sets ambiguous times to null. Later replays keep this state. The 12 focused tests and the final 285 Rust tests passed.

The review changed slot keys from Debug names to fixed protocol labels. This stabilized the new schema1 key contract before integration with storage. The review treated this as part of the new contract.
