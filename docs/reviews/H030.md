# H030 değişiklik incelemesi

7 Kasım2026; ana ajan incelemesi. Durum: kod incelemesi, yerel kapı ve native kabul tamamlandı; H030 kapatıldı. H031 başlamadı.

Değişiklik, pencere kapatma isteğini native tepsi varsa gizlemeye dönüştürür. Tamamen çıkış nonce ile onaylanır, client-config yazarı terminal olarak tutulur ve mevcut verifier → collector → owned runtime → tray kapanışına gider. Config undo/bypass, auth/model/reasoning veya otomatik başlangıç eklenmez. Beklenen yük tek kullanıcı ve tek yerel uygulama sürecidir.

İncelenen bağlı akış: `App → DesktopLifecycle → desktop-events → main.rs commands → Lifecycle/PlanManager → ExitGate → OverviewManager/RuntimeManager/TrayController`; native `CloseRequested` ve tray menüsü bu akışla birlikte okundu. `get_runtime_snapshot`, `set_optimization`, `save_preferences`, config PreviewGuard çağıranları ve mevcut H029 shutdown sözleşmesi kontrol edildi. UI/test devir dilimi tek Luna xhigh tarafından yazıldı; kaynak ve kritik bağlı akışın kabulü ana ajanda. Çalışan tamamlandıktan sonra root devraldı. Süre veya geliştirme token tasarrufu ölçülmedi.

## Düzeltilen somut bulgular

| Before | After | Why |
| --- | --- | --- |
| Tauri event dinleme izni yokken ilk UI okuması da gerçekleşmiyordu. | Yalnız `main` capability'sine `allow-listen`/`allow-unlisten` eklendi; native UI gerçek tray durumunu aldı. | Yeni backend olayı frontend'e ulaşmalı; native hata görünür kalır. |
| Tray projection DTO'da bulunmayan `compression.can_pause` alanını arıyordu. | Gerçek `capabilities.pause`, compression status/generation/revision kullanılır; unit fixture gerçek DTO şeklindedir. | Çalışan motorda Duraklat eylemi kaybolmamalı; stale CAS korunur. |
| Çıkış dialog'u dar görünümde gizlenen sidebar atası içindeydi. | Dialog body portalındadır; native dar görünümde footer çıkış eylemi görünürdür. | Kullanıcı görünmeyen modal/çıkış denetiminde kilitlenmemeli. |
| StrictMode cleanup sonrasında eski async abonelik ikinci effect'in disposed ref'ini görebiliyordu. | Effect'e yerel cancellation guard eklendi; fixture tek canlı abonelik doğrular. | Yinelenen bildirim/abonelik bırakılmamalı. |
| Error decoder TypeScript'te serbest string template üretiyordu. | Doğrulanmış union code'dan message_key türetilir. | Tam build'in gerçek tip kontrolü geçmelidir. |

Native action, ekrandaki acknowledged generation/revision'a bağlıdır; stale menü eylemi ters işleme dönüşmez. Unknown, hazır sayılmaz. Cancel/stale/busy shutdown veya config yazımı başlatmaz. Config hold ile confirmation aynı kritik bölümde alınır. Başlatılmış runtime/tray eylemi mevcut shutdown'ın ardından sınırlı beklenir; yalnız uygulamanın kendi process/port kaynakları yönetilir. Pencereyi gizleme aktif stream'i durdurmaz.

İzole component testi TR/EN/açık/koyu/dar görünüm, portal, focus/ESC/Tab, parent busy, duplicate pending ve stale hata toparlamasını doğruladı. Fixture native/provider kanıtı değildir. H030 yerel kapsamda kabul edildi,29/51; görev sonunda durulur. Windows11 ücretli doğrulaması önceki ücretsiz çalışma kararıyla skipped/not_tested; diğer OS/yayın/installer/uzun yük kanıtı yok.
