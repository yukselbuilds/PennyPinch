## Scope and contracts

- H025a covers a backend collector that runs every 5 seconds while the app is alive. It does not start the engine and reads metadata only from a ready generation owned by the manager. It preserves the runtime actor's Start/Stop ordering. The fixed loopback `/stats?cached=1`, exact TCP peer PID, live process lease, and generation are verified before and after collection. No new controller protocol or auth/model/reasoning change is introduced. The raw HTTP body is limited to 2MiB and total I/O to 1.5s. Payload is neither stored nor sent to the renderer outside the H023 allowlist projection.
- H025b covers H023→H024 upsert and a query/chart for the same period. Last successful capture time, engine generation, and collection status remain distinct from rolling/aggregate/unknown-record coverage. Polling interruption is marked sticky for the measurement session. No all-traffic or exact-loss count is inferred. Trust in the 0.41.0 tokenizer/component is not upgraded. History remains readable while the engine is stopped. On close, stop the collector before the runtime closes its own processes.
- When the desktop lifecycle notification arrives, Overview reads the main window's native visibility. Hiding to tray stops the five-second panel refresh. When the window becomes visible, read once immediately and resume the normal interval. The backend collector continues on its own five-second interval. [Windows evidence](../proofs/tray-lifecycle.md#19-kasım-2026--tepside-genel-bakış-yenilemesi).
- The current runtime generation is 32 hexadecimal characters (`desktop_controller.py` UUID.hex). Collection carries it unchanged. H023 event identity is the same UUID in canonical hyphenated form. Equality is verified by UUID value. Measurement-session ID is a separate canonical UUID. Do not retrofit the runtime or normalization contract to the dashboard.
- H025c provides a single read-only Graphite summary with tokens and percentage together, a session/today/seven_days filter, and sparse time buckets from the same scope. Do not insert 0/interpolated values for empty periods. Do not produce a shared chart/percentage across mixed bases. Measured zero, negative values, B=0, unknown, and errors remain distinct. Intl formatting is available for TR/EN. Data source, time, and retention are visible. A live source by itself is not measured savings.
- H025d provides a real connection record and one next action. A connection does not mean a client/account/chat is running or traffic is verified. H026 covers model/agent/client traffic attribution. H050/H051 cover accounts/chats. Do not arbitrarily assign proxy totals to platform rows. In normal connection flow, Codex installations with the same plan scope/config fingerprint/endpoint and supported-route evidence may be one logical selection. Do not silently switch a stale record or a different plan/profile. Technical binary selection remains under Advanced. Read-only access to Advanced does not acquire the real mutation lock.
- Pause/resume/tray/output/RTK installation and cost calculations are not added in this task. Do not restart the previously rejected Vite dev server or launch it another way. Use isolated Playwright/Computer Use verification on the existing WebView2. Do not install a new browser/Codex.
- For accessible scaling, Settings provides only a per-window WebView zoom of 100/125/150. No persistent preference or OS DPI change. Tauri permission is limited to the main window's webview zoom command. Verify native zoom with actual devicePixelRatio. A narrow CSS viewport check is not evidence of OS scaling.
