`work/proofs/pause/acceptance.json`,151 son aday kaynak/config girdisini, araç/ortamı, replay/unit girdilerini ve native EXE/dist/fixture/runner/runtime artefaktlarını güncel baytlarla programatik karşılaştırır. Önce/sonra veya güncel aday eşleşmeden kabul üretmez. HTTP+WS replay ile gerçek UI kontrolü ayrı koşulardır; bu kayıt, GUI üzerinden aktif model çağrısı yapılmış gibi sunulmaz. Ücretli/gerçek sağlayıcı model çağrısı0; fake upstream usage alanları fatura/kota tasarrufu değildir.

Anthropic pause'da bütün eski mesaj JSON'u aynıdır. Varsayılan motor breakpoint'i resume'da ilerleyebilir: yalnız motorun ürettiği `cache_control` konumu değişebilir, prompt/opaque içerik aynı kalır. Açık client marker/TTL ve eski mesaj JSON'u aynen korundu. Provider cache-hit/indirim doğrulanmadı. Erken fixture önceki `ok` yanıtını geçmişten atlıyordu; düzeltildi. Ayrı Claude senaryoları, motorun exact-response cache'inden cevap almamak için farklı başlangıç metni kullanır.

Replay yalnız RAM'dedir, TTL7200 geçerlidir. Responses güven bütçesi2MiB JSON payload,64 tracker ve64MiB konservatif serialized muhasebedir; fiziksel RSS sınırı ölçülmedi. Güven kanıtlanamazsa pause kapanır; paused istek sabit hata verebilir, kullanıcı resume veya engine restart yapabilir. Executor timeout/cancellation sonrası geç çalışan sonucunun gönderilmiş prefix olduğu varsayılmaz. Kodlama/cache profili her içeriğin sıkışacağını vaat etmez. [Varsayılan cache marker ayrımı ve kaynak](../decisions/016-safe-pause.md).

Yeniden üretim: paketli runtime mevcutken repo kökünden `python tests/runtime/pause_replay.py` çalışır. Birim dosyası aynı embedded Python'un `sys.prefix/exec_prefix` ve `Lib/site-packages` ayarıyla `runpy.run_path(...,run_name='__main__')` üzerinden çalıştırılır; kabulün metadata runner'ı `work/proofs/pause/check.py` içindedir. Yerel ürün kapısı [WORKFLOW](../development/WORKFLOW.md) komutlarıdır; opt-in Rust testi `--ignored --test-threads=1` ister. Ham prompt/secret/HTTP/engine hata çıktısı saklanmadı. Prototip Job terminate kapanışı, üretim graceful stop kanıtından ayrıdır.

Bu kısa yerel replay uzun süreli yük, canlı sağlayıcı, bütün modellerin bütün özellikleri, Windows11/macOS/Linux veya installer kabulü değildir. Destek kataloğu yükseltilmedi; H041 canlı API-key kapısı açıktır. Geliştirme token tasarrufu/süre ölçülmedi. H029 başlamadı.
