The acceptance check `work/proofs/pause/acceptance.json` compares 151 final source and config inputs, the tools and environment, and replay and unit inputs. It checks the native EXE, distribution, fixture, runner, and runtime artifacts against current bytes. It rejects a mismatch between pre-run and post-run inputs or with the current candidate.

The HTTP and WebSocket replays ran separately from the real UI checks. The GUI check made no active model call. The tests made 0 live provider model calls, including paid calls. The fixture's upstream usage fields establish neither billing nor quota savings.

The old message JSON stayed identical during Anthropic pause. The engine can move its default breakpoint when it resumes. Only the engine-generated `cache_control` position can change. The prompt and opaque content stay the same. The test kept the explicit client marker, TTL, and old message JSON. Provider cache hits and discounts remain unverified.

An early fixture omitted the previous `ok` response from history. The test fixed that omission. The separate Claude scenarios use different opening text to avoid the engine's exact-response cache.

Replay stays in RAM and uses TTL 7200. The Responses trust budget is 2 MiB per JSON payload, 64 trackers, and 64 MiB of conservative serialized size accounting. The test did not measure an RSS limit.

If the engine cannot establish trust, the pause path fails closed. A paused request can receive a fixed error. The user can resume compression or restart the engine. After an executor timeout or cancellation, a late result supplies no proof of a sent prefix. Compression depends on the content under the coding and cache profile. [Default cache markers and source](../decisions/016-safe-pause.md)

To reproduce the replay, prepare the packaged runtime. Run `python tests/runtime/pause_replay.py` from the repository root. Use the same embedded Python with `sys.prefix/exec_prefix` and `Lib/site-packages` set. Run the unit file with `runpy.run_path(...,run_name='__main__')`. The acceptance runner is in `work/proofs/pause/check.py`.

Use the commands in the local product gate. The Rust opt-in test requires `--ignored --test-threads=1`. The test retained no raw prompts, secrets, HTTP data, or engine errors. Prototype Job termination has separate evidence from graceful production stop. [WORKFLOW](../development/WORKFLOW.md)
