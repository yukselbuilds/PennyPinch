## PennyPinch 0.1.1-preview.5 for Windows 10

This preview keeps the exit code visible when it compresses successful Codex command output on the Responses route. It forwards failed command output in full. The installer includes Headroom 0.45.0.

### Install or upgrade

1. Compare the ZIP's SHA-256 digest with the value in the `SHA256SUMS.txt` file beside the ZIP.
2. Extract the entire ZIP.
3. Exit PennyPinch from the system tray if it is running.
4. Run `PennyPinch_0.1.1-preview.5_x64-setup.exe`.
5. Select **Do not uninstall** if setup finds the earlier version.
6. Use the current installation folder if you are upgrading.
7. Open PennyPinch.

This preview uses an unsigned installer. The installer needs internet access if WebView2 is missing.

### Verification

The upgrade from 0.1.1-preview.4 passed on Windows 10 22H2 x64. PennyPinch kept the saved test preferences. The installed engine restored the full successful output and forwarded the complete failed output. Windows 11 x64 verification remains open.
