# PennyPinch 0.1.1 for Windows

PennyPinch 0.1.1 is the first stable release for Windows 10 22H2 x64. It uses Headroom engine 0.45.0.

## Upgrade from preview.8

Use the full installer in this ZIP to upgrade from PennyPinch 0.1.1-preview.8.

1. Close PennyPinch if it is open.
2. Extract the full ZIP into a folder.
3. Run `PennyPinch_0.1.1_x64-setup.exe`.
4. If the installer finds preview.8, select **Do not uninstall**.
5. Keep the current installation folder to preserve the existing installation.
6. Open PennyPinch after setup finishes.

The separate `SHA256SUMS.txt` release asset verifies the ZIP. Check it before you extract the ZIP. The `SHA256SUMS.txt` file inside the ZIP lists the member digests. The ZIP also includes third-party notices and license text in `LICENSES/`.

## In-app updates

PennyPinch checks signed update metadata. If an update is available, select **Download and verify**. After verification, select **Update and restart**. Confirm the action when prompted. PennyPinch then closes, applies the update, and reopens.

## Windows security and support

The installer is unsigned and has no Authenticode signature. Windows SmartScreen may show a warning. If WebView2 is missing, the installer needs an internet connection to install it.

A local Windows 10 22H2 x64 test installed and checked this release. Windows 11 x64 validation is still open.

The local upgrade check started from the publicly verified preview.8 installer. It preserved user preferences byte for byte. The installed engine completed one local Responses stream, released its owned port, and exited normally. The check made zero external model calls. The installer reports `NotSigned` for Authenticode.
