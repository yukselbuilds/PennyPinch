## PennyPinch 0.1.1-preview.8 for Windows 10

The Responses route sends repeated tool results through normal output handling. It keeps exact original retrieval for compressed logs. The full installer includes Headroom 0.45.0.

### Install or upgrade

1. Compare the ZIP's SHA-256 digest with the value in the separate checksum file.
2. Extract the entire ZIP.
3. Exit PennyPinch from the system tray if it is running.
4. Run `PennyPinch_0.1.1-preview.8_x64-setup.exe`.
5. Select **Do not uninstall** if setup finds the earlier version.
6. Use the current installation folder if you are upgrading.
7. Open PennyPinch.

This preview uses an unsigned installer. The installer needs internet access if WebView2 is missing.
