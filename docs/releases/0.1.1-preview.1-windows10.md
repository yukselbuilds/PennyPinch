## PennyPinch 0.1.1-preview.1 for Windows 10

This preview adds signed in-app updates for Windows 10 22H2 x64. It includes the Headroom 0.44.0 engine.

### Install or upgrade

1. Download `PennyPinch_0.1.1-preview.1_Windows_x64_preview.zip` from the release assets.
2. Check the ZIP against `SHA256SUMS.txt` from the release assets.
3. Extract the ZIP.
4. Exit PennyPinch from the system tray if it is running.
5. Run `PennyPinch_0.1.1-preview.1_x64-setup.exe`.
6. Open PennyPinch.

If you use v0.1.0, run this installer once in the current installation folder. The installer is unsigned. It needs internet access if WebView2 is missing.

### Get a signed update

1. Open **Settings → App updates**.
2. Select **Preview** as the release channel.
3. Select **Check for updates**.
4. Select **Download and verify** when v0.1.1-preview.2 appears.
5. Stop the engine if it is running.
6. Select **Update and restart**.
7. Select **Continue**.

After the update, **App updates** offers **Restore previous version**. The app verifies the signature and file digests before it installs an update.

### Verification

- The live update and rollback passed on the Windows 10 22H2 x64 development PC.
- The test preferences and local test data remained available after both restarts.
- Clean-host and Windows 11 x64 verification remain open. macOS and Linux packages have separate release checks.
