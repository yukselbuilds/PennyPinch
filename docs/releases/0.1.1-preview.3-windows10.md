## PennyPinch 0.1.1-preview.3 for Windows 10

This security preview updates the bundled OpenTelemetry API to 1.45.2 and Tokio to 1.54.1. The Windows installer removes the old OpenTelemetry package record during an in-place upgrade.

### Install or upgrade

1. Download `PennyPinch_0.1.1-preview.3_Windows_x64_preview.zip` and `SHA256SUMS.txt` from the release assets.
2. Compare the ZIP's SHA-256 digest with the value in `SHA256SUMS.txt`.
3. Extract the ZIP.
4. Exit PennyPinch from the system tray if it is running.
5. Run `PennyPinch_0.1.1-preview.3_x64-setup.exe`.
6. Select **Do not uninstall** if setup finds the earlier version.
7. Use the current installation folder if you are upgrading.
8. Open PennyPinch.

The security patches require the full installer. This preview uses an unsigned installer. It needs internet access if WebView2 is missing.

### Verification

The upgrade from 0.1.1-preview.1 passed on Windows 10 22H2 x64. The app kept the test preferences and local test data. The installed Headroom 0.44.0 engine started and stopped. Windows 11 verification is open.
