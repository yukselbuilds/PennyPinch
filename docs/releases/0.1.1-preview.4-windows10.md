## PennyPinch 0.1.1-preview.4 for Windows 10

This preview updates the bundled Headroom engine to 0.45.0. The full installer removes the old 0.44.0 package metadata during an upgrade.

### Install or upgrade

1. Download `PennyPinch_0.1.1-preview.4_Windows_x64_preview.zip` and `SHA256SUMS.txt` from the release assets.
2. Compare the ZIP's SHA-256 digest with the value in `SHA256SUMS.txt`.
3. Extract the ZIP.
4. Exit PennyPinch from the system tray if it is running.
5. Run `PennyPinch_0.1.1-preview.4_x64-setup.exe`.
6. Select **Do not uninstall** if setup finds the earlier version.
7. Use the current installation folder if you are upgrading.
8. Open PennyPinch.

Use the full installer for the engine upgrade. This preview uses an unsigned installer. The installer needs internet access if WebView2 is missing.

### Verification

The upgrade from 0.1.1-preview.3 passed on Windows 10 22H2 x64. The app kept the saved test preferences. The installed engine completed one local Responses stream and stopped normally. Windows 11 x64 verification remains open. [Installed upgrade evidence](https://github.com/yukselbuilds/PennyPinch/blob/main/docs/proofs/windows-preview4-installed-upgrade.json)
