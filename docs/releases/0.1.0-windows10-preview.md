## PennyPinch 0.1.0 for Windows 10

PennyPinch measures input token savings from local optimization for coding agents.
This first preview includes a Windows x64 installer and the Headroom 0.44.0 engine.

### Install

1. Download `PennyPinch_0.1.0_Windows_x64_preview.zip` from the release assets.
2. Check the ZIP against `SHA256SUMS.txt` from the release assets.
3. Extract the ZIP.
4. Open `PennyPinch_0.1.0_x64-setup.exe`.
5. Start PennyPinch.
6. Follow the [user guide](https://github.com/yukselbuilds/PennyPinch/blob/main/docs/USER_GUIDE.md) to connect a coding tool.

The installer is unsigned. It installs for the current Windows user.
The installer needs internet access if WebView2 is missing.
Download future previews from [GitHub Releases](https://github.com/yukselbuilds/PennyPinch/releases).

### What we verified

- The app installed and ran on a Windows 10 22H2 x64 development PC.
- On one live Codex CLI request, PennyPinch estimated 211 fewer input tokens (1.17%).
  The local estimate went from 18,081 to 17,870 input tokens. [Measurement record](https://github.com/yukselbuilds/PennyPinch/blob/main/docs/proofs/pennypinch-windows10-activity-measurement.json)
- Clean Windows 10 installation and Windows 11, macOS and Linux release checks remain open.
